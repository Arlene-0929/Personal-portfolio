# Personal Portfolio - Arlene's Developer Portfolio

A modern, responsive personal portfolio website built with Next.js, TypeScript, and Tailwind CSS, showcasing web development projects and skills.

## 🌐 Live Demo
Visit the live site: [https://personalportfolio-kappa-gilt.vercel.app/](https://personalportfolio-kappa-gilt.vercel.app/)

## 📁 Repository
GitHub: [https://github.com/Arlene-0929/Personal-portfolio](https://github.com/Arlene-0929/Personal-portfolio)

## ✨ Features

- **Modern Design**: Clean, professional interface with smooth animations
- **Fully Responsive**: Optimized for all device sizes
- **Dark/Light Mode**: Toggle between themes
- **Interactive Elements**: Hover effects and smooth transitions
- **Project Showcase**: Detailed presentation of development projects
- **Contact Form**: Functional contact section
- **Performance Optimized**: Fast loading with Next.js optimizations

## 🛠️ Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components**: Custom React components
- **Icons**: Lucide React
- **Deployment**: Vercel
- **Animations**: CSS transitions and Tailwind animation utilities

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17 or later
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Arlene-0929/Personal-portfolio.git
cd Personal-portfolio
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎨 Customization

### Update Personal Information
Edit the relevant components in `app/components/`:
- `Hero.tsx` - Update name, title, and introduction
- `About.tsx` - Modify personal description
- `Projects.tsx` - Update project details and links
- `Skills.tsx` - Change skills and technologies
- `Contact.tsx` - Update contact information

### Change Colors
Modify the color scheme in:
- `tailwind.config.ts` - Update theme colors
- `app/globals.css` - Change CSS variables

### Add Projects
Add new projects in `app/components/Projects.tsx` by extending the projects array with:
- Title
- Description
- Technologies used
- Live demo link
- GitHub repository link
- Image path

## 📱 Sections

1. **Hero Section** - Introduction and call-to-action
2. **About Section** - Personal background and interests
3. **Projects Section** - Featured development projects
4. **Skills Section** - Technical skills and tools
5. **Contact Section** - Contact form and social links

## 🚀 Deployment

The site is automatically deployed on Vercel. Any push to the main branch triggers a new deployment.

To deploy manually:
1. Push to GitHub
2. Connect repository to Vercel
3. Configure build settings (automatically detected for Next.js)
4. Deploy
